# FinsSim Isaac Lab Tasks Extension

This extension is part of the FinsSimIsaacLab external project. It registers
FinsROV and WarpAUV tasks; the repository README contains the current task
catalog and compatibility boundaries.

See the repository-level [README](../../README.md) for installation and
[`docs/reference/compatibility.md`](../../docs/reference/compatibility.md) for
the compatibility lock.
